# Cyber Security Attacks & Defense Dataset 2026

## Overview

Cyber Security Attacks & Defense Dataset 2026 is a web-based cybersecurity analytics platform developed as part of a Probability & Statistics Complex Problem Solving (CCP) project. The system provides comprehensive analysis of real-world cybersecurity datasets through statistical techniques, machine learning, interactive visualizations, and automated reporting.

The platform is designed to help users understand cybersecurity threats, vulnerabilities, malicious domains, and malicious IP activities through data-driven insights and regression-based predictive analysis.

---

## Project Objectives

* Analyze real-world cybersecurity datasets.
* Apply probability and statistical methods for data interpretation.
* Perform data preprocessing and exploratory data analysis (EDA).
* Train and evaluate regression models.
* Visualize cybersecurity trends and patterns.
* Generate professional analytical reports.
* Present results through an interactive web dashboard.

---

## Datasets Used

### 1. OTX Threat Intelligence Dataset

Contains threat intelligence indicators, attack-related information, and cybersecurity threat observations used for statistical analysis and threat trend evaluation.

### 2. CVE Vulnerabilities Dataset

Includes Common Vulnerabilities and Exposures (CVE) records used to analyze security weaknesses, severity levels, and vulnerability trends.

### 3. Malicious Domains Dataset

Contains suspicious and malicious domain information used for reputation analysis, threat identification, and predictive modeling.

### 4. Malicious IP Dataset

Provides malicious IP intelligence records for network threat assessment, reputation analysis, and cybersecurity monitoring.

## Evaluation Metrics

The regression models are evaluated using:

### Mean Squared Error (MSE)

Measures the average squared difference between actual and predicted values.

### Root Mean Squared Error (RMSE)

Represents the average prediction error in the original scale.

### R² Score

Indicates how well the regression model explains the variance in the dataset.
