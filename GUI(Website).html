About This Project

CCP 2026

Project Overview

This platform was developed as part of a university Complex Computing Project (CCP) for the academic year 2026. The goal is to apply probability, statistics, and machine learning techniques to real-world cybersecurity data to predict and classify threat severity.

The analysis centers on four datasets sourced from OTX AlienVault, NIST NVD, and VirusTotal, representing different facets of the cybersecurity threat landscape. Regression models are trained to predict Threat_Severity across Malicious IP and Malicious Domain datasets.

Technologies Used

  • Python 3.12 / Google Colab — data preprocessing and model training
  • Pandas, NumPy — data manipulation
  • Scikit-learn — LinearRegression, Ridge, Lasso, RandomForestRegressor, GradientBoostingRegressor
  • Matplotlib, Seaborn — visualization in Colab
  • Chart.js 4.4 — interactive browser visualizations
  • jsPDF 2.5 — client-side PDF generation
  • HTML5 / CSS3 / Vanilla JS — frontend platform

Dataset Sources

  • 1_otx_threat_intel.csv — 2,365 threat pulse records from AlienVault OTX, covering attack techniques, malware families, and TLP classifications
  • 2_cve_vulnerabilities.csv — 1,585 CVE entries from NIST/CISA Known Exploited Vulnerabilities (KEV) catalog, including CWE categories and ransomware usage flags
  • 3_malicious_domains.csv — 162 domain records from VirusTotal with vote counts, reputation scores, and threat severity labels
  • 4_malicious_ips.csv — 200 malicious IP records with geolocation, ASN data, vote statistics, TOR node status, and threat severity classification
